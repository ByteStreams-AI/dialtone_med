Plan FAQ

Choosing and expanding your plan.

Start with the tier that matches your current workflow, then add available upgrades as your operational needs change.

What does every DialTone.Med tier include?

Every tier includes a healthcare phone agent configured around practice-approved workflows for patient calls. Essential Answering includes custom branding, call answering, and categorization for appointments, refills, billing, and insurance.

Can capabilities be added without changing tiers?

Yes. Each tier identifies optional upgrades that can be added as a practice needs more messaging, operational tools, integrations, or analytics.

Which tier supports EMR and EHR integration?

Patient Connect offers EMR integration as an upgrade. Practice Operations includes EMR integration and offers EHR integration as an upgrade. Enterprise Network includes EHR integration.

Which tier supports multiple practice locations?

Enterprise Network includes multi-site support for healthcare groups managing patient calls across multiple locations.
